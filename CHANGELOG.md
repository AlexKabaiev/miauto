- **Стовпець «Постачальник» у замовленнях:** Додано поле постачальника у таблицю позицій замовлень з автокомплітом на основі завантаженого списку постачальників, автоматичною підстановкою сумісних постачальників із каталогу товарів, розширенням вікна замовлення до 1250px та оптимізацією ширини інших колонок.

### Змінено
- **Аналітика та дашборд:** Повністю виключено скасовані замовлення (зі статусом `Скасовано`) з усіх фінансових показників, графіків динаміки прибутку/обороту, історії замовлень по періодах та аналітики по клієнтах на сторінці «Аналітика» (checkbox ручного перемикання вилучено з інтерфейсу).
- **Аналоги деталей (Варіант 1):** Додано нове текстове поле «Аналоги» (`analogs`) для позицій замовлень та товарів у базі даних (SQLite) та в інтерфейсі користувача з автоматичним автозаповненням при виборі сумісних товарів зі складу.
- **Портативний режим роботи (Option B):** База даних SQLite тепер зберігається локально у теці `data` поруч із файлом `MIAUTO.exe` (замість прихованого системного каталогу `%APPDATA%`). Це забезпечує повну переносимість застосунку на флешках чи мережевих дисках.
- **Діалог перевірки бази при запуску:** Якщо виконуваний файл запускається вперше і не знаходить базу даних `data/miauto.db`, він відображає нативне віконце Windows (tkinter messagebox) з пропозицією створити нову чисту базу даних або вийти.
- **Автоматичне фокусування та прокрутка вікон:** При відкритті будь-якої форми (клієнти, замовлення, товари, постачальники) інтерфейс автоматично сфокусується на ній і плавно прокрутить екран (`scrollIntoView`), щоб панель повністю потрапила у видиму зону (корисно при кліках у низу довгих таблиць).
- **Пріоритетне сортування списку:** У загальному списку клієнтів (фільтр "Всі") активні клієнти (із виконаними замовленнями) автоматично сортуються на самому верху для зручності щоденної роботи.

### Змінено
- **Показник прибутку на дашборді:** Картку «Виручка за місяць» замінено на «Прибуток за місяць». Показник тепер розраховує чистий прибуток (ціна продажу мінус ціна закупівлі помножено на кількість) по позиціях замовлень за поточний місяць (крім скасованих) замість суми платежів.
- **Перейменування статусів клієнтів:** Статус "Пауза" змінено на "На паузі", а статус "Архів" — на "Архівний" у всіх файлах локалізації (українській та російській) та бізнес-правилах бекенду.
- **Початковий статус клієнта:** При додаванні нового клієнта в систему за замовчуванням підставляється статус **"Новий"** (замість "Активний").
- **Компактне компонування форми клієнта:**
  - Чекбокси додаткових ознак (VIP, Борг, Передоплата) тепер розташовуються в один горизонтальний рядок (`flex-direction: row`).
  - Текстове поле "Примітка" звужено до `maxWidth: '400px'` та переведено на компактний режим з автоматичною зміною висоти за текстом (`rows={2}`, авто-розширення).
- **Вилучення дублювання:** Ознаку "Архівний" видалено зі списку додаткових чекбоксів ознак клієнта, оскільки вона повністю дублювала статус "Архівний".

### Виправлено
- **Неспівпадіння поля «Аналог» при створенні замовлень:** Виправлено помилку, через яку введене значення у полі «Аналог» для позицій замовлень не зберігалось при створенні та редагуванні замовлень (додано поле `analogs` до схеми `PositionRead` у методі `_order_to_read` на бекенді).
- **Помилка збереження нових авто для клієнтів:** Виправлено помилку, через яку нові автомобілі, додані у картці клієнта (зокрема для клієнта з ID 98), не зберігались у базі даних (додано поле `vehicles` до схем `ClientCreate`/`ClientUpdate`, оновлено роутери бекенду для синхронізації списку авто та форму `ClientForm` на фронтенді).
- **Помилка видалення постачальника:** Виправлено помилку `IntegrityError` (FOREIGN KEY constraint failed) при спробі видалити постачальника, який зв'язаний з товарами чи позиціями замовлень. Тепер зв'язки автоматично онуляються перед видаленням постачальника.
- **NameError (`Decimal`):** Виправлено критичну помилку на бекенді в файлі `clients.py` (відсутність імпорту класу `Decimal`), через яку список клієнтів падав з кодом 500 і відображав "0 клієнтів".
- **Схема серіалізації:** Додано поле `total_debt` у схему `ClientListItem` для усунення Pydantic валідаційної помилки при завантаженні списку.
- **Фільтр відображення:** Вилучено автоматичне приховування архівних клієнтів у списку за замовчуванням. Тепер клієнти зі статусом "Архівний" відображаються у списку.
