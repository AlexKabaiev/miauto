# Регламент експлуатації та підтримки (Operations Guide) — MIAUTO

## 1. Резервне копіювання (Backup Policy)

Оскільки база даних SQLite є ключовим активом застосунку, регулярне резервне копіювання є обов'язковим.

### Автоматичний скрипт бекапу (`backup.ps1`)
У корені репозиторію наявний PowerShell скрипт `backup.ps1`.
* **Принцип роботи:** Створює знімок бази даних `miauto.db` у каталозі `backups/` із часовою міткою `miauto_backup_YYYYMMDD_HHMMSS.db`.
* **Ротація:** За замовчуванням зберігаються останні 10 резервних копій, старіші видаляються автоматично.
* **Запуск вручну:**
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\backup.ps1
  ```
* **Налаштування планувальника завдань Windows (Task Scheduler):**
  Рекомендується налаштувати щоденний запуск о 19:00:
  ```powershell
  $Action = New-ScheduledTaskAction -Execute "PowerShell.exe" -Argument "-ExecutionPolicy Bypass -File C:\MIAUTO\backup.ps1"
  $Trigger = New-ScheduledTaskTrigger -Daily -At 19:00
  Register-ScheduledTask -TaskName "MIAUTO_Daily_Backup" -Action $Action -Trigger $Trigger
  ```

## 2. Відновлення після аварії (Disaster Recovery)

Якщо файл бази даних пошкоджено або видалено:
1. Зупиніть роботу `MIAUTO.exe`.
2. Перейдіть до папки `backups/`.
3. Оберіть найновіший валідний бекап.
4. Скопіюйте його у папку `data/` та перейменуйте на `miauto.db`.
5. Запустіть `MIAUTO.exe` та перевірте цілісність даних через інтерфейс.

## 3. Моніторинг та діагностика несправностей

### 3.1. Логи застосунку
У консольному вікні або файлі журналу фіксуються:
* Запити Uvicorn з кодами відповідей HTTP (200, 404, 500).
* Помилки валідації Pydantic (422 Unprocessable Entity).
* Винятки взаємодії з SQLite (наприклад, помилки блокування бази `sqlite3.OperationalError: database is locked`).

### 3.2. Типові інциденти та рішення

| Симптом | Можлива причина | Дія для усунення |
| :--- | :--- | :--- |
| **Порт 8421 зайнятий** | Попередній процес `MIAUTO.exe` не завершився коректно | Завершити процес `MIAUTO.exe` або `python.exe` через Диспетчер завдань |
| **Помилка завантаження курсів валют** | Відсутнє підключення до Інтернету або Monobank rate limit | Застосунок автоматично використовує локальні кешовані курси. Перевірити з'єднання |
| **База даних заблокована (locked)** | Одночасний доступ або паралельне копіювання файлу | Переконатися, що SQLite працює у режимі WAL, завершити сторонні блокуючі процеси |
