# Інструкція з тестування (Testing Strategy) — MIAUTO

## 1. Загальна стратегія

Тестування проекту MIAUTO охоплює:
* **Unit та інтеграційні тести бекенду:** Перевірка бізнес-логіки розрахунків маржі, замовлень, клієнтів, обробки помилок та ендпоінтів FastAPI.
* **Перевірка типів та компіляція фронтенду:** Контроль типізації TypeScript та валідність збірки через Vite.
* **Ручне e2e-тестування:** Перевірка користувацьких сценаріїв у зібраному standalone-режимі.

---

## 2. Тестування бекенду (Backend Tests)

Бекенд використовує `pytest` та клієнт `TestClient` (на базі `httpx`).

### Запуск тестів
```powershell
# Запуск усіх тестів
.venv\Scripts\python.exe -m pytest backend/tests -v

# Запуск з виводом stdout/print
.venv\Scripts\python.exe -m pytest backend/tests -s -v
```

### Структура тестових наборів:
* `backend/tests/test_bugfixes.py` — тести специфічних виправлень, конвертації числових полів та обробки крайових випадків.
* `backend/tests/test_dashboard.py` — тести розрахунку фінансових показників, прибутковості, дебіторської заборгованості та фільтрації замовлень.

---

## 3. Перевірка фронтенду (Frontend Typecheck & Build)

Фронтенд перевіряється компілятором TypeScript на етапі збірки:

```powershell
cd frontend
# Перевірка типів та збірка
npm run build
```

---

## 4. Перевірка перед релізом (Sanity Checklist)

1. **Ізольована база даних:**
   Переконатися, що тестові запуски не модифікують робочу базу `miauto.db`.
2. **Скрипт генерації вигаданих даних (Seed):**
   ```powershell
   python -m app.seed
   ```
   Перевірити, що генератор створює коректні замовлення, клієнтів та довідники без персональних даних реальних осіб.
