# Product Requirements Document (PRD) — MIAUTO

## 1. Огляд продукту

**MIAUTO** — це спеціалізований десктопний бізнес-застосунок, розроблений для автоматизації роботи менеджерів з продажу автозапчастин, столів замовлень та сервісних центрів.

### Основна проблема
Ведення замовлень автозапчастин у звичайних таблицях (Excel/Google Таблиці) або загальних CRM призводить до:
* Помилок під час ручного конвертування валют (закупівля в EUR/USD, продаж у UAH).
* Втрати контролю за статусами виконання замовлень від різних постачальників.
* Складнощів із фіксацією передплат та заборгованостей клієнтів.
* Ризику витоку клієнтської бази при використанні сторонніх хмарних систем.

### Рішення
Автономний локальний застосунок із web-інтерфейсом, який працює повністю автономно без обов'язкової інтернет-реєстрації, гарантує повну конфіденційність бази даних (SQLite) і надає зручний інтерфейс для обліку автозапчастин, замовлень та клієнтів.

---

## 2. Цільова аудиторія та сценарії (User Personas)

1. **Менеджер столу замовлень автозапчастин:**
   * Швидке створення замовлення під конкретне авто (VIN, марка, модель).
   * Додавання запчастин з артикулами, ціною постачальника та націнкою.
   * Розрахунок прибутку в реальному часі.
   * Друк або експорт замовлення для клієнта.
2. **Власник бізнесу / Керівник:**
   * Перегляд фінансової аналітики та загального прибутку за період.
   * Контроль заборгованостей клієнтів за неоплаченими замовленнями.
   * Надійне локальне зберігання бази без підписок та хмарних ризиків.

---

## 3. Функціональні вимоги (Functional Requirements)

### 3.1. Керування клієнтами
* Створення, редагування та перегляд карток клієнтів (ПІБ, телефон, примітки, знижка).
* Історія всіх замовлень конкретного клієнта.
* Баланс взаєморозрахунків (сума оплат vs вартість виконаних замовлень).

### 3.2. Облік та обробка замовлень
* Створення нового замовлення з прив'язкою до клієнта.
* Статуси замовлення: `Новий`, `В обробці`, `Очікує доставки`, `Готово до видачі`, `Видано`, `Скасовано`.
* Додавання позицій: артикул, назва, виробник, кількість, закупівельна ціна, валюта закупівлі (EUR/USD/UAH), відсоток націнки, кінцева ціна продажу.
* Автоматичний підрахунок собівартості, загальної суми, отриманої передплати та залишку до сплати.

### 3.3. Довідники та інтеграції
* Довідник постачальників з контактами та умовами співпраці.
* Інтеграція з Monobank API для отримання актуальних готівкових та безготівкових курсів USD та EUR з кешуванням.
* Імпорт історичних даних з попередніх облікових систем (CSV / Excel).

### 3.4. Фінансова звітність та дашборд
* Ключові метрики на головній сторінці: обсяг продажів за місяць, чистий маржинальний прибуток, кількість відкритих замовлень, дебіторська заборгованість.

---

## 4. Нефункціональні вимоги (Non-Functional Requirements)

* **Продуктивність:** Час відповіді API локального сервера < 50мс для вибірок до 10 000 замовлень.
* **Автономність:** Можливість повноцінної роботи без інтернет-з'єднання (з використанням кешованих або ручних курсів валют).
* **Портативність:** Запуск як єдиний `.exe` файл без необхідності попереднього встановлення Python, Node.js або окремої СУБД.
* **Безпека:** Локальний хостинг (binding на `127.0.0.1`), відсутність передачі персональних даних у хмару.
* **Надійність:** Регулярне резервне копіювання бази даних SQLite у каталог бекапів із можливістю швидкого відновлення.
