# Инструкция пользователя приложения MIAUTO (Менеджер Стол Заказов)

Добро пожаловать в инструкцию пользователя приложения **MIAUTO**! Этот документ поможет вам быстро разобраться с функционалом программы и настроить рабочие процессы для эффективного учета заказов и клиентов.

---

## 1. Запуск приложения и портативный режим

Приложение работает в полностью портативном режиме (Portable). Это означает, что программу и ее данные можно хранить на флешке или в любой папке на компьютере.

### Шаги для запуска:
1. Убедитесь, что файл **`MIAUTO.exe`** и папка **`data/`** (в которой находится файл базы данных `miauto.db`) расположены в одной директории.
2. Запустите файл **`MIAUTO.exe`** двойным кликом.
3. Программа проверит наличие базы данных:
   * **Если база найдена:** Приложение мгновенно запустится в фоновом режиме и автоматически откроет окно управления в вашем браузере по адресу `http://127.0.0.1:8421`.
   * **Если база не найдена:** На экране появится окно с запросом: *"База данных не найдена. Создать новую пустую базу?"*
     * Нажмите **"Да"**, если запускаете приложение впервые и хотите создать новую чистую базу данных.
     * Нажмите **"Нет"**, если вы забыли скопировать существующую базу. Программа завершит работу, чтобы вы могли перенести файл `miauto.db` в папку `data` рядом с EXE.

> [!WARNING]
> **Важно:** Не распаковывайте и не запускайте программу из папки `C:\Program Files`, так как система безопасности Windows (UAC) может заблокировать возможность сохранения данных в файл базы. Лучшее место для запуска — диск `D:\` или отдельная папка на Рабочем столе / в Документах.

## 2. Модуль "Клиенты"

Для перехода к базе клиентов выберите пункт **"Клиенты"** в левом боковом меню.

### 2.1. Создание нового клиента
* Нажмите кнопку **"+ Новый клиент"** в верхнем правом углу.
* Введите ФИО или название фирмы, телефон, email, ИНН (при наличии), название компании и индивидуальную скидку.
* По умолчанию при создании нового клиента подставляется статус **"Новый"**.
* Нажмите **"Создать"** для сохранения.

### 2.2. Статусы клиента и правила их изменения
Система использует 5 логических статусов для управления базой покупателей:
1. **Новый:** Клиент, который только что зарегистрирован и не имеет ни одного выполненного заказа.
2. **Активный:** Клиент, у которого есть хотя бы один выполненный заказ в системе. Статус присваивается автоматически при переводе заказа в состояние "Выполнено".
3. **На паузе:** Клиент, работа с которым временно приостановлена.
4. **Проблемный:** Клиент, имеющий системные нарушения (просроченные оплаты, частые отказы и т.д.). При выборе этого статуса обязательно нужно выбрать причину проблемности и оставить комментарий.
5. **Архивный:** Клиент, история заказов которого сохранена, но сейчас он не совершает активных покупок. По умолчанию отображается в общем списке.

### 2.3. Дополнительные признаки клиента (Flags)
Наряду со статусом клиенту можно назначить дополнительные признаки:
* **VIP:** Предоставляет клиенту особую отметку в списке (звездочка ★ VIP).
* **Есть долг (⚠️):** Вычисляется **автоматически**. Если у клиента есть задолженность по заказам > 0.01 грн, флажок автоматически устанавливается и появляется в списке. Ручное управление этим признаком отключено.
* **Требует предоплату (⇅):** Отмечает клиентов, работа с которыми ведется исключительно при условии аванса.
* **Рисковый (⚡):** Особая отметка для клиентов из группы риска.

### 2.4. Сортировка и поиск клиентов
* В списке клиентов по умолчанию (когда выбран фильтр "Все") первыми отображаются **Активные** клиенты, так как они являются ядром ежедневной работы. Все остальные статусы идут ниже.
* Поиск работает по ФИО, названию фирмы или телефону. Также слева есть поле поиска по точному **Коду клиента** (ID).
* Если вы открываете клиента, который находится в самом низу длинного списка, экран плавно скроллится и фокусируется на открытом окне.

### 2.5. История статусов
При каждом изменении статуса клиента система фиксирует автора изменения (имя менеджера), дату и комментарий. Историю изменений можно просмотреть в нижней части карточки клиента.

## 3. Модуль "Заказы"

Основной экран работы менеджера — **"Заказы"**.

### 3.1. Создание нового заказа
1. Нажмите **"+ Новое заказ"** в правом верхнем углу.
2. Выберите клиента:
   * Можно ввести уникальный **Код клиента** в левое поле — система подтянет данные автоматически.
   * Или начните вводить имя / телефон в поле поиска клиента справа.
3. Выберите автомобиль клиента (если он привязан в карточке).

### 3.2. Предупреждение о статусе клиента (Alerts)
При выборе клиента система проверяет его статус и признаки и выводит цветные баннеры-предупреждения в верхней части формы:
* ⛔ **Красный баннер:** Клиент является **Проблемным** (выводится точная причина и примечание менеджера). Будьте внимательны при оформлении заказа!
* ⚠️ **Оранжевый баннер:** Клиент имеет **Долг** (выводится точная сумма долга). Рекомендуется напомнить об оплате.
* ⇅ **Синий баннер:** Клиент требует **обязательной предоплаты**.

### 3.3. Добавление позиций заказа
* Введите код детали. Если деталь есть в базе, система предложит варианты автозаполнения названия, производителя и цен.
* Укажите количество, закупочную цену и цену продажи.
* Выберите статус каждой детали отдельно (Ожидает заказа, Заказано, На складе, Выдано клиенту и т.д.).

### 3.4. Оплата и завершение заказа
* Укажите сумму, которую клиент уплатил в поле **"Сплачено"** (Оплачено). Программа автоматически рассчитает прибыль и задолженность (Борг / Долг).
* **Критическое правило бизнес-логики:** Заказ **невозможно** перевести в статус **"Виконано"** (Выполнено), если клиент не оплатил его полностью (Долг должен быть равен 0.00 грн). Система заблокирует попытку и покажет предупреждение.

## 4. Модуль "Аналитика"

Доступен через пункт меню **"Аналітика"** (Аналитика). Это отдельный модуль для анализа деятельности, содержащий:
* **Общие финансовые показатели:** Выручка, чистая прибыль, средняя наценка, общая задолженность клиентов.
* **Сезонность продаж:** Графики объема заказов по месяцам для планирования закупок.
* **Топ клиентов:** Рейтинг покупателей по объему заказов и принесенной прибыли. Нажатие на клиента в рейтинге открывает детальное окно со статистикой его заказов и оплат.
* **Анализ заказов по статусам:** Круговая диаграмма распределения заказов по этапам выполнения.

## 5. Резервное копирование данных (Бэкапы) и выход из программы

В приложении внедрена надежная гибридная система резервного копирования базы данных для защиты от сбоев и потери информации.

### 5.1. Автоматический бэкап при выходе
* Для завершения работы с приложением используйте кнопку **"🚪 Выход"** в самом низу левого бокового меню.
* При нажатии на кнопку программа:
  1. Автоматически создаст резервную копию базы данных под названием `miauto_auto_backup_ГГГГММДД.zip` (где `ГГГГММДД` — текущая дата). Копия сохраняется в папке `backups/` рядом с `MIAUTO.exe`.
  2. Проверит папку `backups/` и оставит в ней **только 5 последних автоматических архивов** (самые старые удаляются автоматически, чтобы не засорять жесткий диск).
  3. Остановит фоновую консоль сервера Uvicorn и безопасно завершит работу приложения. На экране браузера появится сообщение о том, что работа завершена и вкладку можно закрыть.

### 5.2. Ручное создание копии (Точки восстановления)
* Если вы хотите создать резервную копию вручную (например, перед важными работами или перед обновлением), нажмите кнопку **"💾 Бэкап"** в верхнем правом углу шапки приложения.
* Программа создаст архив вида `backups/miauto_manual_ГГГГММДД_ЧЧММСС.zip` (с точным указанием даты и времени создания).
* **Важно:** ручные резервные копии **никогда не удаляются автоматически** системой. Вы должны самостоятельно контролировать их количество в папке `backups/` и при необходимости копировать их на флешку или в облачное хранилище.
