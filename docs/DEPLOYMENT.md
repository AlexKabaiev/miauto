# Інструкція з розгортання та збірки (Deployment Guide) — MIAUTO

Цей документ описує процес збірки standalone-дистрибутива `.exe` та перенесення програми на робочі комп'ютери користувачів.

---

## 1. Системні вимоги для збірки

* **ОС:** Windows 10 або Windows 11 (64-біт).
* **Python:** 3.10+ (рекомендовано 3.11).
* **Node.js:** 18+ з менеджером пакетів `npm`.
* **PyInstaller:** 6.x.

---

## 2. Покроковий процес збірки релізу

### Крок 1. Підготовка віртуального оточення бекенду
```powershell
uv venv
.venv\Scripts\Activate.ps1
uv pip install -r backend/requirements.txt
uv pip install pyinstaller
```

### Крок 2. Збірка клієнтського інтерфейсу (Frontend)
```powershell
cd frontend
npm ci
npm run build
cd ..
```
*Результат:* скомпільовані статичні файли HTML, JS, CSS у директорії `frontend/dist/`.

### Крок 3. Пакування у standalone EXE через PyInstaller
```powershell
.venv\Scripts\pyinstaller --clean miauto.spec
```
*Результат:* готовий автономний файл `dist/MIAUTO.exe`.

### Крок 4. Створення демо-пакета для користувачів (GitHub Releases)
Для створення готового ZIP-архіву для Windows із попередньо заповненою синтетичною базою даних:
```powershell
python package_demo.py
```
*Результат:* готовий архів `release/MIAUTO-v1.0.0-demo-windows.zip`, який можна завантажити у [GitHub Releases](https://github.com/AlexKabaiev/miauto/releases). Користувачеві достатньо розпакувати його та запустити `MIAUTO.exe`.

---

## 3. Розгортання на цільовому робочому місці (Production Deployment)

1. Створіть робочу директорію на комп'ютері користувача, наприклад:
   ```text
   C:\MIAUTO\
   ├── MIAUTO.exe
   ├── data\
   │   └── miauto.db
   └── backups\
   ```
2. Скопіюйте `dist/MIAUTO.exe` у створену папку `C:\MIAUTO\`.
3. Якщо це нове встановлення:
   - Папка `data/` та первинна база даних створяться автоматично під час першого запуску `MIAUTO.exe`.
4. Якщо це оновлення існуючої версії:
   - Закрийте запущений процес `MIAUTO.exe`.
   - Зробіть резервну копію поточної бази даних (`data/miauto.db`).
   - Замініть старий `MIAUTO.exe` новим скомпільованим файлом.
   - Запустіть оновлений `MIAUTO.exe`. Вбудовані міграції автоматично адаптують схему бази даних.

---

## 4. План відкату (Rollback Procedure)

У разі виявлення критичних помилок після оновлення:
1. Завершіть процес `MIAUTO.exe` через Диспетчер завдань або комбінацію `Ctrl + C` у консолі.
2. Відновіть попередню версію файлу `MIAUTO.exe` із резервної копії релізу.
3. Відновіть файл `data/miauto.db` зі створеної перед оновленням точки збереження.
4. Перезапустіть додаток та перевірте відкриття замовлень.
