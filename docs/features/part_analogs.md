# Аналоги деталей (Cross-references)

Цей функціонал дозволяє зберігати інформацію про взаємозамінні запчастини (аналоги / кроси) як у каталозі товарів, так і в позиціях конкретних замовлень.

## Використання

1. **В замовленні:** При створенні чи редагуванні замовлення праворуч від поля «Код» з'являється поле «Аналог». У ньому можна вказати аналоги оригінального артикулу (наприклад, через кому: `530011310, WL7401`).
2. **В картці товару:** У редакторі товару на складі доступне поле «Аналоги», куди можна вписати сумісні артикули для полегшення майбутнього пошуку та підбору запчастин.
3. **Автозаповнення:** Якщо оригінальний код вводиться в позицію замовлення і збігається з кодом наявного на складу товару, поле «Аналоги» буде заповнено автоматично даними з картки товару.
