# MIAUTO — Стіл замовлень автозапчастин

**MIAUTO** — це настільний бізнес-застосунок для менеджерів автомагазинів та сервісних центрів. Він призначений для оптимізації обліку клієнтів, обробки замовлень, ведення каталогу товарів, постачальників та аналізу фінансових показників.

Застосунок поєднує гнучкість веб-технологій та зручність настільного ПЗ завдяки автоматичному запуску локального сервера та відкриттю інтерфейсу в браузері.

---

## 📥 Швидкий запуск демо-версії для Windows (без середовища розробки)

Якщо ви бажаєте протестувати або продемонструвати можливості застосунку на вашому комп'ютері (Windows 10/11), вам **не потрібно встановлювати Python, Node.js або окрему СУБД**:

1. Завантажте готовий архів **`MIAUTO-v1.0.0-demo-windows.zip`** зі сторінки [GitHub Releases](https://github.com/AlexKabaiev/miauto/releases).
2. Розархівуйте файли у будь-яку папку на диску (наприклад, `C:\MIAUTO\`).
3. Запустіть файл **`MIAUTO.exe`** (двічі клацніть лівою кнопкою миші).
4. Програма автоматично підніме локальний сервер та відкриє інтерфейс у браузері (`http://127.0.0.1:8421`).
5. **Демо-база включена:** Пакет уже містить демонстраційну базу даних `data/miauto.db` з реалістичними, але повністю синтетичними замовленнями, клієнтами, позиціями та постачальниками.

> Для розробників: спакувати свіжий демо-архів можна командою `python package_demo.py`.

## 🛠️ Технологічний стек

* **Бекенд (API Server):**
  * **FastAPI** (Python 3.10+) — високопродуктивний асинхронний веб-фреймворк.
  * **SQLAlchemy 2.0** — ORM для взаємодії з базою даних.
  * **SQLite** — легка, надійна локальна база даних у портативному режимі.
  * **Uvicorn** — ASGI-сервер для запуску застосунку.

* **Фронтенд (UI):**
  * **React** + **TypeScript** — бібліотека для побудови інтерфейсу.
  * **Vite** — швидкий інструмент збірки фронтенду.
  * **Vanilla CSS** + **Material Design** — сучасний, швидкий та адаптивний інтерфейс.

* **Дистрибуція (Packaging):**
  * **PyInstaller** — пакування бекенду та фронтенду в єдиний виконуваний файл `.exe` для Windows.

## 🚀 Інструкція для розробників

### 1. Налаштування віртуального середовища (Python)
Проект використовує інструмент **uv** для швидкого керування віртуальними середовищами та залежностями.

1. Переконайтеся, що у вас встановлено Python 3.10+ та `uv`.
2. Створіть віртуальне оточення:
   ```bash
   uv venv
   ```
3. Активуйте віртуальне оточення:
   * **Windows (PowerShell):**
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   * **Linux/macOS:**
     ```bash
     source .venv/bin/activate
     ```
4. Встановіть залежності бекенду:
   ```bash
   uv pip install -r requirements.txt
   ```

### 2. Налаштування фронтенду
1. Перейдіть до папки фронтенду:
   ```bash
   cd frontend
   ```
2. Встановіть залежності Node.js:
   ```bash
   npm install
   ```

### 3. Наповнення бази даних демо-даними
Після клонування репозиторію база даних порожня. Для заповнення вигаданими демо-даними виконайте з теки `backend`:
```bash
py -m app.seed
```
Скрипт створить таблиці та наповнить базу реалістичними, але повністю вигаданими записами (клієнти, замовлення, товари, постачальники тощо).

### 4. Запуск у режимі розробки (Development)
Для локальної розробки запускаються окремо сервер бекенду та dev-сервер фронтенду:

* **Запуск бекенду (з кореневої теки проекту):**
  ```bash
  .venv\Scripts\python.exe -m app.main
  ```
  Сервер API буде доступний за адресою `http://127.0.0.1:8421`.

* **Запуск фронтенду (з папки `frontend`):**
  ```bash
  npm run dev
  ```
  Фронтенд буде доступний за адресою `http://localhost:5173`. Запити до API автоматично проксуються на порт `8421`.

## 📦 Збірка дистрибутива (Standalone EXE)

Пакування застосунку в один файл `MIAUTO.exe`, який містить у собі весь фронтенд та бекенд:

1. Скомпілюйте фронтенд для продакшену (з папки `frontend`):
   ```bash
   npm run build
   ```
   Це створить статичні файли в папці `frontend/dist`.

2. Запустіть збірку PyInstaller (з кореневої папки проекту):
   ```bash
   .venv\Scripts\pyinstaller --clean miauto.spec
   ```

3. Після успішного завершення збірки:
   * Виконуваний файл **`MIAUTO.exe`** з'явиться в папці `dist/`.
   * Для перенесення застосунку достатньо скопіювати файл `MIAUTO.exe` та створити поруч теку `data/` з файлом бази даних `miauto.db`.
